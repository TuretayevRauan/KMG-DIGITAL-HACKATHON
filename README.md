# KMG GeoHub — геологическая AI-система (RAG)

Система вопросов-ответов по геологическим / нефтепромысловым документам.
Загружаете документы (PDF, DOCX, TXT и др.) → задаёте вопросы на русском → получаете
ответы со ссылками на источник `[документ:страница]`.

**Стек:** FastAPI (бэкенд) + Streamlit (фронтенд) + Qdrant (векторный поиск) +
BM25 (ключевые слова) + OpenRouter (open-weight модели). Neo4j (граф) — опционально.

---

## 1. Требования

- **Python 3.11**
- Ключ **OpenRouter** (для генерации ответов) — https://openrouter.ai/keys
- (опционально) **Neo4j** + Docker — только для реального графа знаний

---

## 2. Установка (один раз)

В папке проекта:

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл **`.env`** в корне проекта:

```
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
```

---

## 3. Запуск

Нужно **2 окна терминала**. В каждом сначала активируйте venv: `venv\Scripts\activate`

### Окно 1 — бэкенд (FastAPI, порт 8000)

```bat
python app/main.py
```

Признак успеха: `Uvicorn running on http://0.0.0.0:8000`.
Проверка: открыть в браузере `http://localhost:8000` → должен вернуться JSON
`{"status":"работает", ...}`.

### Окно 2 — фронтенд (Streamlit, порт 8501)

```bat
streamlit run frontend/streamlit_app.py
```

Автоматически откроется `http://localhost:8501` — это и есть сайт **KMG GeoHub**.

> ⚠️ Оба окна должны работать одновременно. Бэкенд запускайте первым.

## 5. Граф знаний (опционально)

Раздел «Граф знаний» работает **без Neo4j** — показывает демо-вид.

Чтобы включить реальный граф:

1. Положите `app/graph_api.py` в папку `app/`.
2. В `app/main.py` сразу после `app = FastAPI(...)` добавьте 2 строки:
   ```python
   from graph_api import router as graph_router
   app.include_router(graph_router)
   ```
3. Запустите Neo4j (Docker) и перезапустите бэкенд.
4. Диагностика: `http://localhost:8000/graph_debug` покажет статус подключения.

## 6. Частые проблемы

| Симптом | Причина / решение |
|---|---|
| `Backend недоступен` во фронтенде | Окно 1 (бэкенд) не запущено или упало — посмотрите ошибку в нём |
| Ответ `timed out` | Бесплатная модель перегружена (429) — повторите запрос |
| `404` от модели | ID бесплатной модели устарел — проверьте на openrouter.ai/api/v1/models (`:free`) |
| Из документа не извлёкся текст | Скан без текста — нужен OCR (`USE_LOCAL_OCR=1` + Tesseract с русским пакетом) |
| Граф недоступен | Норма без Neo4j — показывается демо-вид |
